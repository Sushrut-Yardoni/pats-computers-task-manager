# PATS - VS Code Setup & Supabase Database Configuration Guidelist

Welcome! This guide outlines step-by-step instructions to configure your local machine, set up Visual Studio Code, create your Database in Supabase (with full DDL queries), and connect it directly to your application backend or frontend.

## 🗄️ 3. Setup Database in Supabase

We use Supabase (built on PostgreSQL) for cloud-integrated relational storage. Follow these steps to build the datastore:

### Step 1: Create a Project
1. Log in to [Supabase Dashboard](https://supabase.com).
2. Click **New Project** and select your organization.
3. Choose a project name (e.g., `PATS-Service-Dispatch`), set a secure Database Password, and select the region closest to you.
4. Click **Create New Project** and wait for it to provision (~1-2 minutes).

### Step 2: Open SQL Editor
1. In the Supabase sidebar, select **SQL Editor** (the terminal `SQL` icon).
2. Click **New Query** to open a black canvas.
3. Copy/paste the entire SQL script block below to create your tables and seed default rows.

## 🔌 5. Connect the Database to Your Project

### 🔑 Step 1: Copy Your API Credentials
1. Go to your Supabase Dashboard sidebar and select **Project Settings** (the gear cog ⚙️).
2. Select **API**.
3. Under **Project API keys**, locate:
   - **`anon public`** key.
   - **Project URL** (e.g. `https://xxx.supabase.co`).

### 📁 Step 2: Configure Environment Variables
Create a file named `.env` inside your project's root directory (on the same level as `package.json`), and add your credentials:

```env
# Supabase Live Connection Credentials
SUPABASE_URL="https://your-project-id.supabase.co"
SUPABASE_ANON_KEY="your-anon-public-key-here"
```

### ⚡ Step 3: Use the Connection in the Code
Your project already has `@supabase/supabase-js` installed and configured inside `src/lib/supabaseClient.ts`:

```typescript
import { supabase } from "./lib/supabaseClient";

// Example pattern to load live employees directly from Supabase:
const fetchEmployees = async () => {
  const { data, error } = await supabase
    .from('employees')
    .select('*')
    .eq('ended_at', null);

  if (error) {
    console.error("Database connection failed", error);
  } else {
    console.log("Employees fetched:", data);
  }
}
```

## 🚀 6. Running and Testing Locally

1. Open your VS Code editor at the root directory of the project.
2. Fire up a terminal (`Ctrl+` ` ` or `View -> Terminal`) and run:
   ```bash
   # Install local package node_modules
   npm install

   # Start the Express server + Vite frontend developer environment
   npm run dev
   ```
3. Open `http://localhost:3000` in your web browser. The app runs, and automatically integrates your live database capabilities depending on settings. Enjoy coding!
